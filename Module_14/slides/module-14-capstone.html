🎯 Capstone objectives

  • Synthesize 13 modules into one coherent architecture
  • Produce a labeled architecture diagram with explicit trade-offs
  • Reuse Terraform modules from earlier labs — don't start from scratch
  • Run terraform init + plan cleanly — apply is optional

Set the bar early. A working diagram + clean plan + named decisions is the success criterion. A fully-applied stack is a bonus, not the goal.

📝 Scenario brief

The ask

Design a production-grade 3-tier web application for a mid-size SaaS. ~100K MAU, mostly US, growing into EU next year. Compliance: standard data-protection. Budget: cost-conscious but reliability matters.

Required components

  • VPC with public + private subnets, multi-AZ
  • ALB → ASG (web/app tier)
  • Aurora (relational data) + S3 (assets)
  • CloudFront in front of static + dynamic
  • WAF on the ALB

Decisions to defend

  • Autoscaling trigger (Module 11)
  • Pricing model mix (Module 12)
  • Data store choice (Module 10)
  • Multi-AZ vs. multi-Region (Module 8)
Read the brief out loud. Constraints matter as much as components — cost-conscious changes the answer.
